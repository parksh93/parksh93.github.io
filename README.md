# 포트폴리오 프롬프트 사용 안내

이 문서는 공공 IT 프로젝트 수행 이력을 기반으로 포트폴리오를 제작하기 위한 프롬프트 모음이다.

## 구성
1. 포트폴리오 콘텐츠 작성 프롬프트
2. 포트폴리오 디자인/UI 기획 프롬프트
3. 포트폴리오 웹 구현 프롬프트
4. 통합본 프롬프트

## 사용 방법
- 프로젝트 소개 문구가 필요하면 `01_포트폴리오_콘텐츠_작성_프롬프트.md` 사용
- 화면 구조 및 디자인 방향이 필요하면 `02_포트폴리오_디자인_UI_기획_프롬프트.md` 사용
- 실제 HTML/CSS 초안이 필요하면 `03_포트폴리오_웹_구현_프롬프트.md` 사용
- 한 번에 요청하고 싶으면 `04_포트폴리오_프롬프트_통합본.md` 사용

## 참고
이 프롬프트는 공공기관/행정기관 관련 프로젝트 경험을 보다 전문적이고 신뢰감 있게 표현하는 데 초점을 맞춘다.
단순 이력 나열이 아닌, 수행 경험과 역량 중심의 포트폴리오 제작을 목표로 한다.
